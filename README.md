# 3 Months AI Track

My 12-week plan from ML fundamentals to shipping an Arabic/French/English RAG and agent system, with **Bench**, the local learning platform I study in.

```
platform/   Bench: lessons, labs, checks (FastAPI + one HTML page)
work/       my code, one folder per day (day01 ... day84)
```

| Weeks | Phase | Topic |
|---|---|---|
| 1 | Phase 0 | Fundamentals + GitHub |
| 2 | Phase 1 | LLM basics and serving |
| 3 | Phase 1 | RAG from scratch |
| 4 | Phase 1 | Evaluation |
| 5 | Phase 1 | Tool calling and agents |
| 6 | Phase 1 | Real Arabic data |
| 7-12 | Phase 2 | Scope, build, evaluate, ship and present one project |

## Run it

1. `setup.bat` once (creates `.venv`, installs `requirements.txt`).
2. `start.bat`: Bench opens at http://127.0.0.1:8766, with your code read from and saved to `work/`.

Details in [platform/README.md](platform/README.md).
