# Aliases and identity
**Topic:** assignment never copies; `id()` shows which object a name points to.

## Your mission
Show the difference between an alias and a copy, then explain `+=` versus `+` on a list.

## Steps
1. `b = ...`: make `b` point to the same list as `a`.
2. `c = ...`: make `c` a new list with the same values (`a.copy()`).
3. Predict `x` and `y` in part 3 before running. One mutates in place, one rebinds.
4. Fill `WHY_X_CHANGED` and `WHY_Y_DID_NOT` in your own words.

## Done when
**Check** confirms `b is a`, `c is not a`, and both explanations are written.
